# The Outsiders Ch. 1–6 Study Guide

A single-page static site. No build step.

## Deploy to Vercel (command line)
1. Install Node.js from nodejs.org if you don't have it.
2. Open a terminal in this folder.
3. Run `npx vercel` and log in when asked. Accept the defaults.
4. Run `npx vercel --prod` to publish to your live URL.

## Deploy to Vercel (GitHub)
1. Create a new GitHub repository and upload these files.
2. On vercel.com, click Add New → Project and import the repository.
3. Framework preset: Other. Leave build settings empty. Click Deploy.
